# versions/

Per-Minecraft-version subprojects generated by [Stonecutter](https://stonecutter.kikugie.dev/).

Each `versions/<mc>/gradle.properties` overrides two values from the root `gradle.properties`:

- **`fabric_api_version`** — the Fabric API build compatible with that Minecraft version.
- **`minecraft_dependency`** — the string written into `fabric.mod.json` so the produced jar declares the correct Minecraft it supports (e.g. `1.21.4` for the 1.21.4 build).

All other build logic lives in the root `build.gradle.kts` and is shared across every subproject.

## Supported versions

`1.21.2`, `1.21.3`, `1.21.4`, `1.21.5`, `1.21.6`, `1.21.7`, `1.21.8`.

## Build outputs

Compiled jars end up in `versions/<mc>/build/libs/`. A single `./gradlew build` from the repository root builds every version in parallel.

## Adding a new version

1. Add the version string to the `versions(...)` list in `stonecutter.gradle.kts`.
2. Create `versions/<new-mc>/gradle.properties` with the two overrides above.
3. Add any needed Stonecutter `//? if` wraps in the sources to handle API drift.
4. Update the CI matrix in `.github/workflows/build.yml` and `.github/workflows/release.yml`.
