# Casinocraft

Fabric-мод для Minecraft **1.21.5**. Добавляет казино-механику: слот-машина (блок), казино-фишки как валюта, ставки и выплаты.

## Стек

- Minecraft 1.21.5
- Fabric Loader 0.19.3+
- Fabric API 0.128.2+1.21.5
- Java 21

## Разработка

```bash
# Запустить клиент из IDE-конфига или через Gradle
./gradlew runClient

# Собрать jar
./gradlew build
```

Готовый jar — в `build/libs/`.
